# Product requirements document

## Problem and user

Small businesses and agencies can generate AI-assisted copy but may not know if
it improves a business outcome. The first user runs an opted-in email A/B test
with one primary binary conversion outcome.

## Phase 2 scope

Typed frozen configuration, deterministic allocation, terminal outcome events
and a synthetic machine/human-readable report. Action is blocked under SRM or
unresolved missing outcomes.

## Non-goals

No email sending, external ingestion, multi-user access, PII persistence, LLM,
creative authoring, sequential stopping, multi-arm analysis, revenue metric or
hosting exists.
