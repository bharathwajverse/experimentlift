# Security and privacy

Phase 2 has generated synthetic IDs only: no network listener, customer-data
store, cloud model call, credentials or email sender.

A hosted product must apply workspace authorization, secret-manage and never
log assignment salts, minimize/retain/delete personal data under documented
rules, and control audit logs. Real commercial email requires consent,
suppression/unsubscribe handling and jurisdiction/provider review. CAN-SPAM and
GDPR are references, not a compliance certification.
